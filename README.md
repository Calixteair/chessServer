# chessServer
Serveur Java multi thread de mon jeu d'echec


## Description
Server Java multi thread de mon jeu d'echec


## Installation
1. Cloner le projet
2. Importer le projet dans votre IDE
3. Lancer le serveur avec la commande
```bash
mvn exec:java -Dexec.mainClass="com.chessserver.server.ChessServer"
```
4. Lancer le client
5. Jouer
